# Silent Auction

A simple Python silent auction program created as part of my **100 Days of Code** Python learning journey.

## What It Does

The program allows multiple people to enter their names and bids. After all bidders have entered their bids, the program determines who placed the highest bid and announces the winner.

## How It Works

1. The program asks for the bidder's name.
2. The bidder enters their bid.
3. The program asks whether there are additional bidders.
4. Each bidder and their bid are stored in a dictionary.
5. Once bidding is finished, the program loops through the dictionary.
6. The highest bid is found.
7. The winner and their bid are displayed.
